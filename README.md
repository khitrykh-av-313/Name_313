## Часть 1: Табличный датасет (Credit & Carbon)

### Данные 💾
Используемый в проекте датасет был взят с **[Kaggle](https://www.kaggle.com/datasets/deepashukla/unified-credit-and-carbon-dataset-for-rural-ai?resource=download)** , а для скачивания доступен по следующей ссылке:

### **[Unified Credit & Carbon Dataset for Rural AI (Google Drive)](https://drive.google.com/file/d/10zWddY15usCdpocAaw-xI-Ixy0sHwi8w/view?usp=drive_link)**

Датасет содержит финансовые, психометрические, категориальные, числовые и геопространственные признаки.
- Объём файла: 1,2 МБ
- Количество записей: 5 000
- Количество признаков: 33
- Финансовые признаки: ~15
- Агро-экологические признаки: ~12
- Спутниковые/дистанционные признаки: 4
- Целевые переменные: 2 (кредитный рейтинг и класс почвенного углерода)

### Установка и запуск :jigsaw:
#### План step-by-step

1. **Клонируйте репозиторий** на свой компьютер (это загрузит код проекта):
   ```bash
   git clone https://github.com/khitrykh-av-313/Name_313.git
   cd Name_313
   ```
2. Установите зависимости из файла requirements.txt. Выполнить эту команду в любом удобном терминале (Git Bash, PowerShell, cmd или встроенный терминал VS Code):
   ```
   pip install -r requirements.txt
   ```

3. Запустите скрипт для загрузки и просмотра датасета:
   ```
   python data_loader.py
   ```

#### Ожидаемый результат :sparkles:
  После запуска скрипта в консоль выведутся:

- Размер датасета (количество строк и столбцов).
- Первые 10 строк датасета.
- Приводит типы данных к правильным (текстовые колонки в `category`, время в `datetime`).
- Сохраняет обработанный датасет в формат `.parquet` для дальнейшего анализа.

## Часть 2: API-эспрессо: Датасет из кофейной энциклопедии :coffee:
Был проведён опрос публичного API **[Энциклопедии кофе (BrewFYI)](https://brewfyi.com/ru/)**. 
С помощью скрипта `read_api.py` был собран структурированный датасет, содержащий информацию о различных сортах кофе, их генетических группах, высоте произрастания и оценках качества.

**Инструменты:** `requests` (для запросов) и `pandas` (для формирования таблицы).
**Результат:** Файл `coffee_varieties.csv` (не загружается в репозиторий, добавлен в `.gitignore`).
