# ⋄ Name_313 ⋄
Репозиторий для тренировочного проекта.
В процессе над его работой было выполнено два независимых задания: 
1.  Обработка табличного датасета: Загрузка, приведение типов и сохранение в Parquet.

3. Работа с базами данных: Чтение учетных данных из SQLite и запись данных в PostgreSQL.

## Часть 1: Табличный датасет (Credit & Carbon)

### Данные :floppy_disk:
Используемый в проекте датасет был взят с **[Kaggle](https://www.kaggle.com/datasets/deepashukla/unified-credit-and-carbon-dataset-for-rural-ai?resource=download)** , а для скачивания доступен по следующей ссылке:

### **[Unified Credit & Carbon Dataset for Rural AI (Google Drive)](https://drive.google.com/file/d/10zWddY15usCdpocAaw-xI-Ixy0sHwi8w/view?usp=drive_link)**

Датасет содержит финансовые, психометрические, категориальные, числовые и геопространственные признаки.
- Объём файла: 1,2 МБ
- Количество записей: 5 000
- Количество признаков: 33
- Финансовые признаки: ~15
- Агро-экологические признаки: ~12
- Спутниковые/дистанционные признаки: 4
- Целевые переменные: 2 (кредитный рейтинг и класс почвенного углерода)

### Установка и запуск :jigsaw:
#### План step-by-step

1. **Клонируйте репозиторий** на свой компьютер (загружает код проекта):
   ```bash
   git clone https://github.com/khitrykh-av-313/Name_313.git
   cd Name_313
   ```
2. Установите зависимости из файла requirements.txt. Выполнить эту команду в любом удобном терминале (Git Bash, PowerShell, cmd или встроенный терминал VS Code):
   ```
   pip install -r requirements.txt
   ```

3. Запустите скрипт для загрузки и просмотра датасета:
   ```
   python data_loader.py
   ```

#### Ожидаемый результат :sparkles:
  После запуска скрипта в консоль выведутся:

- Размер датасета (количество строк и столбцов).
- Первые 10 строк датасета.
- Приводит типы данных к правильным (текстовые колонки в `category`, время в `datetime`).
- Сохраняет обработанный датасет в формат `.parquet` для дальнейшего анализа.

## Часть 2: Сбор данных через API (Coffee)

### Данные :floppy_disk:
Был проведён опрос публичного API **[Энциклопедии кофе (BrewFYI)](https://brewfyi.com/ru/)**. 
С помощью скрипта `read_api.py` был собран структурированный датасет, содержащий информацию о 72 сортах кофе, их генетических группах, высоте произрастания и оценках качества.

### Библиотеки :books:
Для сбора и обработки данных из API используются:
- `requests` — для отправки HTTP-запросов к API.
- `pandas` — для формирования и обработки таблицы.

### Установка и запуск :jigsaw:

1. **Клонируйте репозиторий** на свой компьютер (если еще не сделали этого):
   ```bash
   git clone https://github.com/khitrykh-av-313/Name_313.git
   cd Name_313
   ```
2. Установите зависимости из файла requirements.txt. Выполнить эту команду в любом удобном терминале (Git Bash, PowerShell, cmd или встроенный терминал VS Code):
   ```
   pip install -r requirements.txt
   ```
3. Запустите скрипт для сбора данных из API:
   ```
   python read_api.py
   ```

### Ожидаемый результат :sparkles:
После запуска скрипт:

Выведет в консоль логи процесса сбора данных (с указанием даты и времени).
- Соберет данные о 72 сортах кофе.
- Создаст файл coffee_varieties.csv в корневой папке проекта.
- Выведет первые 10 строк собранного датасета.

## Часть 3: Работа с базой данных

### Описание задачи :card_file_box:
В рамках задания необходимо было прочитать учетные данные из локального файла SQLite (`creds.db`) и записать первые 100 строк собранного датасета в удаленную базу данных PostgreSQL в таблицу, названную фамилией и именем студента.

### Библиотеки :books:
Для работы с базами данных используются:

- `sqlite3` — встроенный модуль Python для чтения локальной базы creds.db.
- `sqlalchemy` — для управления подключением и выполнения запросов к PostgreSQL.
- `psycopg2-binary` — драйвер для подключения к PostgreSQL.

### Установка и запуск :jigsaw:
> [!WARNING]
> Для работы скрипта в корне проекта должен находиться файл `creds.db` с учетными данными. Этот файл добавлен в `.gitignore` и **не попадает** в репозиторий по соображениям безопасности.

Запустите скрипт для загрузки данных в БД:
```
python scripts/write_to_db.py
```

### Ожидаемый результат :sparkles:
После запуска скрипт:

- Прочитает доступы из `creds.db`.
- Подключится к удаленной базе данных `homeworks`.
- Запишет 100 строк в таблицу *Khitrykh_Alyona* (или ваше ФИО/название).
- Выведет сообщение об успешной записи.
